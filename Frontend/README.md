# Interview AI

Interview AI is a full-stack application that analyzes a target job description and a candidate profile to produce a personalized interview-preparation plan. Authenticated users can submit a job description, provide a self-description and optionally upload a PDF résumé. Google Gemini generates structured interview guidance that can be reviewed in the application and used to generate a tailored résumé PDF.

This implementation is based on the learning reference and original Interview AI project by Ankur (Ankur's Interview AI project).

## Features and workflows

### Authentication

- Register with a username, email, and password.
- Log in and log out using an HTTP cookie containing the JWT.
- Protected application routes redirect unauthenticated users to `/login`.

### Interview planning

1. Sign in and open the protected home page.
2. Paste a target job description.
3. Either upload a PDF résumé or enter a quick self-description.
4. Generate an interview strategy through the backend and Gemini.
5. Review the generated match score, skill gaps, technical questions, behavioral questions, and day-by-day preparation roadmap.
6. Return to previously generated reports from the home page.

### Résumé generation

From an interview report, the application can request a tailored résumé from Gemini and download it as a PDF generated by Puppeteer.

## Technology stack

- Frontend: React, React Router, Axios, Sass, Vite
- Backend: Node.js, Express, Mongoose, Multer, `pdf-parse`, Puppeteer
- Database: MongoDB
- AI: Google Gemini through `@google/genai`
- Authentication: JWT cookies with bcryptjs password hashing

## Architecture

The repository contains two independently installed applications:

```text
Frontend/
  React UI, routing, authentication context, interview screens, API clients

Backend/
  Express server, authentication and interview routes, controllers, models,
  Gemini service, MongoDB configuration, résumé upload and PDF generation
```

The frontend runs on port `5173` and calls the backend at `http://localhost:3000`. The backend applies CORS for that local frontend origin and stores users, blacklisted tokens, and interview reports in MongoDB.

## Prerequisites

- Node.js 20.19+ or 22.12+
- npm
- A MongoDB deployment, such as MongoDB Atlas
- A Google AI Studio API key with access to the Gemini API

## Installation

Clone the repository, then install each application separately:

```bash
cd Backend
npm install

cd ../Frontend
npm install
```

## Environment setup

Create `Backend/.env` locally. Never commit this file or paste real values into documentation:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_long_random_jwt_secret
GOOGLE_GENAI_API_KEY=your_google_gemini_api_key
```

The repository ignores environment files. A sanitized `.env.example` may be committed if desired, but it must contain placeholders only.

## Running locally

Start the backend in one terminal:

```bash
cd Backend
npm run dev
```

The API listens on `http://localhost:3000`.

Start the frontend in another terminal:

```bash
cd Frontend
npm run dev
```

Open the Vite URL shown in the terminal, normally `http://localhost:5173`. Register an account before opening the protected interview-planning page.

## Production build

Build the frontend with:

```bash
cd Frontend
npm run build
```
